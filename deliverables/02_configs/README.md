## How each Mac's system settings were changed (all reversible with `restore_network.sh`)

| Mac | Root step | Commands |
|---|---|---|
| mac_vachan | dnsmasq as a root service; DNS -> itself; trust CA | `brew services start dnsmasq` (as root), `networksetup -setdnsservers Wi-Fi 10.7.23.136`, `dscacheutil -flushcache; killall -HUP mDNSResponder`, `security add-trusted-cert -d -r trustRoot -p ssl -k /Library/Keychains/System.keychain tls/ca.crt` |
| mac_aanya | DNS -> mac_vachan; trust CA | `networksetup -setdnsservers Wi-Fi 10.7.23.136`, flush, `security add-trusted-cert ...` (nginx itself runs as a normal user: macOS allows binding :443 on the wildcard address) |
| mac_abhay | DNS -> mac_vachan; trust CA | the same as mac_aanya |

Original DNS settings were saved before any change (`state/original_network.txt` on each Mac).
