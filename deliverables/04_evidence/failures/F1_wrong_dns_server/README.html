Layer and why

DNS (application-level name lookup) vs IP connectivity (network layer). Name resolution failed completely, yet the path to the edge was fine at L3 (ping) and L4 (TCP handshake to 443), and the whole HTTPS exchange worked once the IP was supplied without DNS. DNS is a separate service that only turns names into addresses. If the client asks a server that doesn't exist, it can't get an address, even though the network, the edge and the backends are healthy. Diagnosis rule: when dig fails but ping <ip> works, look at the resolver configuration (scutil --dns), not at the network.
