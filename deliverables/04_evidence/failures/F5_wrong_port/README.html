Layer and why

Transport layer: IP addresses and ports are separate identifiers. The IP address (network layer) got the packets to the right machine: it answered ping and completed a handshake on 443. The port (transport layer) names the service on that machine. On 8444 no socket is listening, so the edge's TCP stack answers the SYN with a RST, which the client reports as "connection refused". A refusal (RST) proves the host is reachable and the service is missing; a timeout would instead suggest a firewall silently dropping packets or a dead host.
